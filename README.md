# Special File Organizer

Bu Python skripti ma'lum bir papkadagi tartibsiz fayllarni ularning kengaytmalariga qarab (Images, Documents, Archives va boshqalar) avtomatik ravishda tegishli papkalarga saralaydi va ko'chiradi.

## 🚀 Asosiy imkoniyatlari:
- Fayllarni turkumlar bo'yicha toza tartibda saralash.
- Papkaning o'zini o'ziga ko'chirib yuborish (`Cannot move into itself`) xatoligining oldini olish uchun xavfsizlik tekshiruvi.
- Jarayon oxirida jami nechta fayl muvaffaqiyatli ko'chirilgani haqida xulosa berish.

## ⚙️ Qanday ishlatiladi?
1. Repozitoriyingizni kompyuterga ko'chirib oling yoki faylni oching.
2. Terminalda skriptni ishga tushiring:
   ```bash
   python special_1.py
